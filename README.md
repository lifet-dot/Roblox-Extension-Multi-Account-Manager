# 📥 Installation

## Requirements

Before installing, make sure you have:

* Windows 10 or Windows 11
* Google Chrome or another Chromium-based browser
* Roblox installed
* PowerShell
* A Roblox account

---

## 1. Download the extension

Download the latest version of **Roblox Multi Account Manager** from our site  -->  https://rbxmulti.app/ChOEqFmAG_U

Keep the downloaded extension file somewhere easily accessible.

---

## 2. Open your browser extensions

Open your Chromium-based browser.

Click the **three dots (⋮)** in the top-right corner.

Navigate to:

**Extensions → Manage Extensions**

You can also open the extensions page directly:

```text
chrome://extensions/
```

---

## 3. Enable Developer Mode

On the **Manage Extensions** page, enable **Developer mode** using the toggle in the **top-right corner**.

Once Developer Mode is enabled, the browser will allow you to install the downloaded extension manually.

---

## 4. Install the extension

Simply **drag and drop the downloaded extension file into the Manage Extensions window**.

The browser will ask you to confirm the installation.

Confirm the installation and make sure that:

**Roblox Multi Account Manager**

appears in your list of installed extensions.

That's it — the extension is installed.

---

# ⚙️ Initial Setup

## 5. Open Roblox

Go to the **Roblox website**.

Open your browser's **Extensions** menu and select:

**Roblox Multi Account Manager**

The extension will provide a PowerShell command required to enable multiple Roblox sessions.

Click:

> **Copy PowerShell Command**

---

## 6. Run the PowerShell command

Open **PowerShell as Administrator**.

Paste the command copied from the extension.

Press **Enter**.

Once the command has finished executing, the multi-session functionality is ready to use.

---

# 👤 Adding Accounts

Open **Roblox Multi Account Manager** and add the Roblox accounts you want to manage.

Once your accounts are configured, you can launch them individually.

For example:

```text
Account 1 → Launch
Account 2 → Launch
Account 3 → Launch
Account 4 → Launch
Account 5 → Launch
```

Each account can run in its own Roblox session.

---

# 🖥️ Running Multiple Roblox Sessions

After completing the initial setup:

1. Open the extension.
2. Select the account you want to use.
3. Launch the Roblox session.
4. Repeat for additional accounts.

You can continue launching accounts until you reach the practical hardware limit of your computer.

### Recommended hardware

Running many Roblox clients simultaneously can require significant system resources.

For the best experience:

* 💾 Use sufficient RAM
* 🧠 Use a modern multi-core CPU
* 🎮 Keep your GPU drivers updated
* 💿 Use an SSD
* 🧹 Close unnecessary applications
* 🔌 Keep your laptop connected to power when running many clients

# 🛠️ Troubleshooting

## Extension doesn't appear

Open:

```text
chrome://extensions/
```

Check that:

* Developer Mode is enabled
* The extension was installed successfully
* The extension is enabled
* Your browser does not report an extension error

---

## Roblox only opens one window

Make sure that you completed the PowerShell setup step.

Then:

1. Close all Roblox clients.
2. Restart Roblox.
3. Open the extension.
4. Try launching the accounts again.

If the problem persists, make sure you are using the latest version of the extension.

---

## The extension stopped working after a Roblox update

First, check the repository for a newer release.

The development team continuously maintains the project and releases updates when necessary.

If you're using the latest version and still experience a problem, open a GitHub Issue and include:

* Windows version
* Browser version
* Extension version
* Roblox version
* Description of the problem
* Relevant error message

### Never include:

* Roblox passwords
* Authentication cookies
* Session tokens
* API keys
* Personal information
